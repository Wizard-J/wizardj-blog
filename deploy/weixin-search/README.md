# 微信普通聊天的网页搜索

此目录记录线上已验证的增量补丁。它适用于接入网页搜索前的 `gpt-chat.mjs`。原文件的 SHA-256 为 `ae6e5be47ceaddeb2f36a93b2db428bd5b0e1d9d9680d9a6c68fe3145852e6a5`。

补丁为使用项目 API 密钥的普通聊天启用按需网页搜索。回复会从已完成的搜索结果中提取引用，去重后附上来源链接。订阅授权分支、微信路由和其他服务配置无需参与。

在原文件的备份目录先运行 `patch --dry-run -p1 < web-search.patch`，确认后应用补丁，再用 `node --check gpt-chat.mjs` 检查。部署后用一条明确要求查证最新信息的普通消息验收，核对回复中的来源链接和微信收发。密钥与服务环境由现有部署提供。

## 停用云端执行入口

在已应用网页搜索补丁的版本上，对 `cloud-bridge.mjs` 和 `gpt-chat.mjs` 所在目录应用 `disable-exec.patch`。先用 `patch --dry-run -p1` 检查，再用 `patch -p1` 应用，并对两个文件运行 `node --check`。旧命令固定回复「云端执行未启用」，普通聊天也会直接说明执行当前不可用。部署后分别验收普通聊天、网页搜索及旧命令的提示。
